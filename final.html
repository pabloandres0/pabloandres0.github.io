Project development

This is a timeline of every advancement done to the final project.

15.09.2026.

Client Proposal

Hypothetical client proposal for an RPG prototype with turn-based combat, dialogue system, and a stylized art style.

Moodboard

Visual research including gameplay features and unique interface ideas.

Sketches

Our first hand-drawn sketches we made in order to explore character poses, battle screen layouts, and interface elements.

Lineart & Clean

David refined the rough drawings into clean digital lineart.

Artstyle Choice

We generated 3 concepts using our sketches to try and figure out the game's visual theme. We chose a futuristic artstyle after comparing the three images generated with Gemini and Nano Banana 2.

18.10.2026.

Portfolio Creation

This website was published for the first time on my GitHub Pages.

02.11.2026.

Pablo's Transcoding

HUD and combat interface elements inspired by Dieter Rams' classic Braun ET66 calculator aesthetic.

03.11.2026.

David's Transcoding

David took inspiration from the TV show Arcane, which features a unique artsyle and coloring techniques.

14.11.2026.

Color Palettes

We defined two color palettes, one serves for general usage and the other will serve for special situations. Both of these use monochromatic colors.

Figma Migration

I moved all interface assets, dialogue boxes, and combat layouts into Figma to make a modular UI component library and make my designs accesible to David.

16.11.2026.

User Flow

We made a mapping of the UX flow. It visualizes the navigation between main menus, battle triggers, dialogue branches, and decision states.

Artificial Forest

David, designed a level featuring a digital forest simulation with virtual enemies where players practice combat and mechanics.

Great Mullen

David also made a sketch of a futuristic city featuring flexible, shiny street surfaces and modern, curved, architectural roads.

22.11.2026.

Progress Overview

This was our attempt to make the actual game in the game. Unfortunately, due to the deadline we weren't able to make much progress.
